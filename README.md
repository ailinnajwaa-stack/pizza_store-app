# Lab 04: Pizza Store App---

A Flutter application developed as part of **Lab 04**, featuring named routes, order management, and automated widget/unit tests.

## Features
- **Menu & Detail Screens:** Browse available food items and view detailed options.
- **Named Routes:** Clean navigation flow between application screens.
- **Order Summary:** Real-time calculation and review of active orders.
- **Unit & Widget Testing:** Includes robust test suites (`order_summary_test.dart`, `pizza_store_test.dart`) to ensure reliable performance.
